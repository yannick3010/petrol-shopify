# Petrol Club

Shopify theme for **Petrol Club** — an automotive social club and third-wave coffee shop in San Clemente, CA.

Classic cars. Craft coffee. One roof.

## Setup

This is a Shopify 2.0 theme. To develop locally:

1. Install the [Shopify CLI](https://shopify.dev/docs/themes/tools/cli)
2. Run `shopify theme dev` to preview changes
3. Push to `shopify/theme` branch for deployment

## Brand

- **Colors:** Black, white, red accents on a light background
- **Fonts:** Bricolage Grotesque (headings), Roboto Mono (body)
- **Logo assets:** `assets/petrol-club-*`
